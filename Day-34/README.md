# 📘 Day 34 – PLC Analog Signals & Process Variables

## 🎯 Learning Objective

Today I am focusing on how PLCs work with real-world process measurements.

Unlike digital signals that are typically ON/OFF, analog signals represent continuously varying values such as:

- Tank level
- Pressure
- Temperature
- Flow
- Speed
- Position

The goal is to understand how these physical measurements become usable values inside a PLC.
